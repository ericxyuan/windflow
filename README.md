# Windflow desktop fan

Engineering prototype in progress, 2026-10-03. **This is not a manufacturing release.**

The original [Onshape design](https://cad.onshape.com/documents/5ca1b5b26cd9a4a93dde4737/w/6d3d38529391b53ad011b362/e/4ed72084c2e4978faf960789) was inspected and preserved in **Baseline - original dual fan and iris - 2026-09-08**. The **Rev B — Native parametric airflow** studio now contains a rounded inlet, radial straightener and progressive-nozzle study as five real parts. The [81-component integrated development assembly](https://cad.onshape.com/documents/5ca1b5b26cd9a4a93dde4737/w/6d3d38529391b53ad011b362/e/3c99f91ec444444536245cd7) includes the repaired housing halves and purchased-component models. Native interference review found only internal vendor-model overlaps and the intentional encoder/wheel engagement. See the [inspection record](cad/onshape-inspection.md) and [implementation plan](docs/implementation-plan.md).

Local CAD now contains a straight airflow head with an integrated outlet in two structural halves, a rounded bell-mouth, a trial radial straightener, guards, magnetic grille and keepers, a single-servo yoke mechanism, removable linkage cover, horizontal thumbwheel, three lighting systems and a removable electronics tray. These are real parametric B-reps with STEP/STL exports, but the routed carrier PCB, interlock mount and complete harness/tubing integration remain unfinished. Files called `REF-` are explicitly approximate envelopes; vendor files have a separate [model register](cad/model-register.md).

The modular Pico firmware compiles, and 6,343 host assertions pass. It implements progressive boost, feedback/pressure protection, startup, night mode, service calibration and validated settings storage. No physical electronics have been tested. Read [firmware operation](docs/firmware-operation.md), [calibration](docs/calibration.md), [BOM](hardware/BOM.md), [wiring](hardware/wiring.md), [power budget](hardware/power-budget.md) and [electrical review](hardware/circuit-review.md). The specified custom carrier circuit still needs schematic capture and PCB layout.

Physical airflow, acoustics, servo calibration, protection thresholds, print tolerances, magnet retention and thermal performance must be tested before qualification. [Deliverable status](docs/deliverable-status.md) separates completed work from unfinished engineering and physical tests.
