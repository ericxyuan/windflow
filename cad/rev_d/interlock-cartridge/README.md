# Historical independent cartridge snapshot

These candidate parts and reports were checked against the 65-group main stage at commit **69df4468a0dfb357583ba9e83957447f6df0d717**. That commit preserves their matching sources and baseline. Their input hashes intentionally do not describe the later 108-group adopted main assembly.

Current integrated parts live directly in `cad/rev_d`. Use `stage-validation.json`, `mesh-validation.json`, `motion-validation.json`, `cartridge-service-validation.json` and `integration-export-validation.json` there for the current article. `tools/build_rev_d_cad.ps1` rebuilds and checks the adopted geometry. The standalone pilot refuses to reapply its geometry operations to an already integrated stage.

The original 4,008 nominal and 196,561 service comparisons remain historical development evidence. Physical fit, switch operation, thermal-insert retention, connected main loom and rotor operation remain unqualified.
